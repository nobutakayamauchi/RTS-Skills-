# Title
Skill Builder

## Purpose
Define or update a reusable skill with clear scope, inputs, process, outputs, and guardrails.

## Use When
- A new repeatable workflow appears.
- An existing skill is ambiguous, bloated, or inconsistent.

## Inputs
- Desired outcome
- Operating constraints
- Target domain and audience
- Known failure patterns (if any)

## Process
1. Clarify the skill objective and non-goals.
2. Define minimal required inputs.
3. Draft concise operational steps.
4. Define output format and validation checks.
5. Add guardrails and stop conditions.
6. Add handoff notes for future operators.

## Output Format
- Skill definition summary
- Final `SKILL.md` sections
- Open questions and follow-up actions

## Guardrails
- Keep the skill reusable and concise.
- Avoid tool lock-in unless explicitly required.
- Do not mix domain-specific assumptions into generic skills.

## Stop Conditions
- Objective, process, and output contract are clear.
- No unresolved ambiguity blocks use.

## Handoff Notes
Provide what changed, why, and which assumptions still need validation.
