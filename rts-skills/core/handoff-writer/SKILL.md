# Title
Handoff Writer

## Purpose
Prepare a clear continuation package for the next operator or model.

## Use When
- Work is paused, transferred, or review-ready.
- Another operator must continue with minimal ambiguity.

## Inputs
- Current status
- Completed tasks
- Remaining tasks
- Risks and assumptions

## Process
1. Summarize completed work.
2. State current status and blockers.
3. List next ordered actions.
4. Separate verified facts, assumptions, and open questions.
5. Include references needed to continue quickly.

## Output Format
- Current State
- Completed
- Next Steps
- Risks
- Assumptions
- Open Questions

## Guardrails
- Optimize for quick continuation.
- Avoid hidden context.

## Stop Conditions
- Successor can continue without re-discovery.
- Critical ambiguities are explicitly listed.

## Handoff Notes
Highlight first action to take on resume.
