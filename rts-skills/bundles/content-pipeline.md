# Content Pipeline Bundle

## Goal
Create a coherent growth-content package from offer definition through distribution assets.

## Included Skills
- offer-clarifier
- sales-page-builder
- seo-brief-writer
- post-repurposer
- image-brief-writer
- thumbnail-angle-generator

## Recommended Execution Order
1. offer-clarifier
2. sales-page-builder
3. seo-brief-writer
4. post-repurposer
5. image-brief-writer
6. thumbnail-angle-generator

## Expected Outputs
- Offer clarity document
- Sales page structure draft
- SEO content brief
- Channel-specific post variants
- Image briefing package
- Thumbnail concept angles

## When Not to Use
- Engineering-only implementation tasks.
- Cases lacking a defined offer or audience baseline.
