# Refactor Bundle

## Goal
Improve structure or maintainability while preserving existing behavior.

## Included Skills
- requirement-clarifier
- scope-locker
- task-decomposer
- safe-implementer
- verification-runner
- change-recorder

## Recommended Execution Order
1. requirement-clarifier
2. scope-locker
3. task-decomposer
4. safe-implementer
5. verification-runner
6. change-recorder

## Expected Outputs
- Refactor target and non-goals
- Protected behavior boundaries
- Ordered refactor tasks
- Minimal reversible change summary
- Behavior verification status
- Risk and follow-up notes

## When Not to Use
- Defect-first work requiring diagnostic flow.
- New feature work with changing acceptance criteria.
