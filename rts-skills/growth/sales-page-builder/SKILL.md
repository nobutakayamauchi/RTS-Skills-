# Title
Sales Page Builder

## Purpose
Structure a clear sales page draft from offer, proof, objections, and call-to-action.

## Use When
- A landing or sales page needs first-pass structure.

## Inputs
- Offer definition
- Audience profile
- Proof and testimonials
- CTA objective

## Process
1. Map page sections in persuasive order.
2. Draft concise section objectives.
3. Align objections with proof.
4. Keep CTA and next action explicit.

## Output Format
- Page Outline
- Section Goals
- Key Messages
- CTA Block

## Guardrails
- No exaggerated claims.
- Keep structure skimmable and evidence-backed.

## Stop Conditions
- Page flow is coherent and conversion-oriented.

## Handoff Notes
Flag missing proof required for final copy.
