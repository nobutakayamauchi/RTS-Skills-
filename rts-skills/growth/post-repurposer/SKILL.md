# Title
Post Repurposer

## Purpose
Transform one source idea into multiple channel-specific post formats.

## Use When
- A core message must be distributed across channels.

## Inputs
- Source content
- Target channels
- Tone constraints
- CTA goal

## Process
1. Extract core message and proof.
2. Map channel-specific format constraints.
3. Produce adapted versions per channel.
4. Preserve claim consistency across outputs.

## Output Format
- Core Message
- Channel Variants
- CTA Variants
- Reuse Notes

## Guardrails
- Do not alter factual claims across versions.
- Keep channel output aligned to original intent.

## Stop Conditions
- Each channel has usable, coherent draft output.

## Handoff Notes
State which variants need compliance or brand review.
