# Title
SEO Brief Writer

## Purpose
Create a practical content brief with search intent, structure, and optimization targets.

## Use When
- A content piece needs SEO-aligned planning.

## Inputs
- Primary topic
- Target audience
- Search intent hypothesis
- Content constraints

## Process
1. Define topic angle and intent.
2. Propose primary and secondary keywords.
3. Build heading structure.
4. Add on-page requirements and quality checks.

## Output Format
- Intent Summary
- Keyword Set
- Outline (H1/H2/H3)
- Optimization Checklist

## Guardrails
- Prioritize reader clarity over keyword stuffing.
- Mark uncertain keyword assumptions.

## Stop Conditions
- Brief is ready for writing without major ambiguity.

## Handoff Notes
Include assumptions requiring validation with SEO data.
