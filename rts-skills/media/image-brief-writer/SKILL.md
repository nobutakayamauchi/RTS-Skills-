# Title
Image Brief Writer

## Purpose
Create clear image briefs that align visual direction with communication goals.

## Use When
- A designer or image model needs structured creative direction.

## Inputs
- Campaign goal
- Audience
- Core message
- Brand constraints

## Process
1. Define image objective and viewer takeaway.
2. Specify composition, subject, and style.
3. Define constraints (brand, legal, technical).
4. Provide success criteria.

## Output Format
- Objective
- Visual Direction
- Constraints
- Acceptance Criteria

## Guardrails
- Avoid ambiguous style requests.
- Separate must-have constraints from optional preferences.

## Stop Conditions
- Brief is actionable without follow-up clarification.

## Handoff Notes
Include unresolved visual decisions and owner.
