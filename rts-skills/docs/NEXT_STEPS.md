# Next Steps

## Who this is for
You already completed one small successful run and want the next step without over-scoping.

## When not to use this page
If you have not completed a first successful run yet, start with onboarding docs instead of this page.

## Immediate next actions
1. Repeat the same workflow once on a slightly larger (still single-area) task.
2. Use `core/scope-locker` before edits.
3. Use `core/verification-runner` to report verified, unverified, and assumptions.

## Second workflow (recommended)
Run one small feature-build flow:
1. `core/requirement-clarifier`
2. `core/task-decomposer`
3. `core/scope-locker`
4. `core/safe-implementer`
5. `core/verification-runner`
6. `core/handoff-writer`

## Third workflow (choose one)
- Reproducible defect -> `bundles/bugfix.md`
- Scoped enhancement -> `bundles/feature-build.md`

## Postpone for now
- Large cross-repo or multi-domain changes
- New bundles before current bundles feel routine
- Deep shell customization before baseline flow is stable

## Revisit growth and media
Revisit `growth/` and `media/` after core engineering flow is stable across multiple runs.
Start earlier only if the immediate task is content, SEO, sales, or creative production.
