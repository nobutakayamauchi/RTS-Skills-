# Naming Conventions

Use lowercase kebab-case for all directories and file names.

## Skills
- Skill directory names: lowercase kebab-case nouns or verb-noun forms.
- Required skill file name: `SKILL.md` (uppercase, fixed convention).
- Examples: `requirement-clarifier`, `safe-implementer`.

## Shell files
- Shell directory names: lowercase environment identifiers (e.g., `codex`, `claude`).
- Shell file names: lowercase kebab-case with `-shell.md` suffix where relevant.
- In this bootstrap set, use: `base-shell.md`, `planning-shell.md`, `implementation-shell.md`, `debugging-shell.md`, `review-shell.md`.

## Bundles
- Bundle file names: lowercase kebab-case ending in `.md`.
- Names should communicate outcome, not team/project labels.
- Examples: `feature-build.md`, `bugfix.md`, `content-pipeline.md`.

## Future extensions
- New top-level domains should use clear lowercase kebab-case (e.g., `research`, `ops`).
- Avoid abbreviations unless they are industry-standard and unambiguous.
- Keep names stable once adopted to preserve references across bundles and shells.
