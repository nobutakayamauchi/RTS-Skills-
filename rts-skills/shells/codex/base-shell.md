# Codex Base Shell

## Goal
Apply core skills with concise, execution-ready instructions in a patch-oriented workflow.

## Operating Style
- Keep directives short and explicit.
- Lock scope before modifying files.
- Use explicit file boundaries for every change.
- Prefer minimal diffs over broad rewrites.

## Skill Invocation Pattern
1. Identify required core skill(s).
2. Restate in-scope files and constraints.
3. Execute with patch-oriented edits.
4. Report changed vs unverified items explicitly.

## Reporting Contract
- Changed files and purpose
- Verification commands run
- Unverified or assumed items
- Next step recommendation
